# Background texture plates

Grayscale 1080x1350 plates the poster renderer washes with a colorway
(postcard.wash_field / the studio's background picker). Committed to the repo
so CI renders and the studio's raw-CDN fetch both see them.

All four are derivatives (grayscale, cropped, blurred) of free Pexels photos.
The Pexels license permits free use and modification without attribution.
